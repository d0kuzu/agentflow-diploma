# Repository working rules

This repository is the home of the AgentFlow diploma project. Keep all changes inside this repository.

- `prob-period-1` is a research and design baseline. Do not claim an application, experiment, interview, review, or deployment exists unless the repository contains verifiable evidence.
- Use synthetic examples. Never commit credentials, customer records, private endpoints, deployment settings, or private reference material.
- `.local-audit/` is local-only and must never be staged, uploaded, or mentioned in public deliverables.
- Keep requirements, diagrams, API contracts, and evaluation plans consistent. Identify proposed behavior and unmeasured targets explicitly.
- Do not fabricate commit history, contributions, YouTrack IDs, client evidence, supervisor feedback, or review approvals.
- Use task branches for subsequent work. Link real YouTrack tasks once the project exists. Preserve submitted tags permanently.
- Keep documentation in English and use the exact approved diploma title.
- Run `python scripts/check_repository.py` after changes to the submission materials.
