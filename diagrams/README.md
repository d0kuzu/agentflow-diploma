# Diagram sources and exports

All diagrams describe a **proposed system** in the analysis/design baseline `prob-period-1`. They do not show an implemented or deployed application.

| View | Editable notation | Readable editable vector |
|---|---|---|
| System context | [context.mmd](context.mmd), Mermaid | [context.svg](context.svg) |
| UML use cases | [use-case.puml](use-case.puml), PlantUML | [use-case.svg](use-case.svg) |
| Draft component architecture | [components.puml](components.puml), PlantUML | [components.svg](components.svg) |

The SVGs are manually laid out vector exports of the same semantic design. Their text, shapes and paths remain editable. They use no embedded screenshot or external font dependency. Open them in a browser or vector editor; open the notation files in an editor supporting Mermaid or PlantUML to revise the structure.

The notation sources do not prescribe identical pixel positioning. Update the source and SVG together when changing an actor, component, relationship or status. Architecture explanations and use-case IDs are in [07-architecture.md](../docs/07-architecture.md). All use cases and software components are planned; arrows indicate proposed interactions and dependencies.
